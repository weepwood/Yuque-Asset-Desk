# 本地数据管理与卸载

Yuque Asset Desk 的程序文件与用户数据分开保存。仅删除应用不会删除用户数据，
也不会删除语雀云端文件。

## 先决定保留范围

在「设置 → 存储与数据 → 管理」中可以打开实际数据目录、统计文件大小、
轻量清理、清除账号凭据或重置本地数据。统计是已识别文件的逻辑大小，
并非文件系统实际分配空间；不计外部备份、未知根目录文件和系统凭据。
扫描会在后台执行，不会访问语雀。统计是快照，数据可能随后变化。

- 轻量清理仅处理 clipboard 目录中符合应用命名规则且内容 SHA256 匹配、
  未被任何账号的任务（含完成任务）或本地 Demo 文件链接引用的普通文件。
  部分写入、无法核实来源的文件、符号链接、重解析点及未知文件不自动删除。
  永久离线微缩图和旧版预览不属于此清理范围。
- 隐私清理仅处理数据库索引中的本应用账号键和当前加载账号。
  已确认不存在的凭据才移除索引；失败保留索引以便重试。
  不清除浏览器 Cookie、其他应用的凭据或环境变量。
  旧版本异常导致的未索引孤立凭据可能需要通过系统凭据界面手动删除。
- 完全重置：先导出备份，另存需要的剪贴板原图；备份只包含数据库、预览，
  不包括凭据或剪贴板原图。先解决所有账号的 pending / paused / running /
  failed / unknown 等未完成任务，再点击重置、阅读警告并二次确认。
  已保存凭据必须清除成功才启动退出清理。退出辅助进程等待实例锁释放，
  重新核对任务与账号索引，只删除本应用识别的数据库、预览和暂存文件。
  不递归删除整个目录，不删除外部原始文件、外部备份或语雀云端。
  未知文件和空实例锁文件可能保留；失败时可能留下 reset-error.txt，
  部分清理不可回滚。出现错误应先检查该报告，不要盲目重试。
  若应用异常退出导致 .reset-request 残留，确认所有应用和清理进程都已退出后，
  可手动删除该标记，再重新打开应用检查数据。不要在清理运行期间移除标记。

## macOS ARM64

1. 如果要保留数据，只需从托盘选择退出（或 Command+Q），将
   /Applications/Yuque Asset Desk.app 移入废纸篓，并弹出 DMG。
2. 若不再使用应用，可先在应用内执行隐私清理或完全重置，确认进程退出、
   数据清理结束后，再移除 .app。
3. 默认数据目录：`~/Library/Application Support/com.Weepwood.YuqueAssetDesk/`。
   Finder 的“前往文件夹”可以打开此目录；自定义 YUQUE_DATA_DIR 优先。
4. 在钥匙串访问中仅核对本应用专属项，键以
   `https://yuque.com/yuque-asset-desk/account/` 开头。不要删除其他语雀或浏览器凭据。
5. 完成清理后可手动移除空的数据目录或无用下载的 DMG。系统的最近使用记录、
   偏好和诊断记录可能仍由 macOS 保留；本应用不承诺擦除操作系统痕迹。

## Windows x64

1. 当前是便携 ZIP / EXE，不注册传统卸载器。退出托盘应用后删除 EXE
   或仅包含应用程序的解压目录；若目录混有其他用户文件，只删除应用文件。
2. 默认数据目录：`%LOCALAPPDATA%\Weepwood\YuqueAssetDesk\data\`。
   如果配置了 YUQUE_DATA_DIR，请以应用显示路径为准。
3. 不需要保留数据时，先使用应用内的清理/重置辅助，再退出并删除程序。
4. 在 Windows 凭据管理器中仅核对本应用专属账号键，
   不要删除其他应用或浏览器凭据。Windows 实际凭据展示名称以系统界面为准。
5. 操作系统缓存、最近使用及诊断记录可能仍存在。

本应用不会主动注册系统服务、驱动或开机自启动。卸载不会撤销语雀服务端会话，
如需要撤销服务端会话，应在语雀账户安全设置中处理。
